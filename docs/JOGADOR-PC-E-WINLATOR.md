# Jogador — Windows e Android/Winlator

## Requisitos

- WoW 3.3.5a build 12340 obtido legalmente;
- conta criada pelo dono do servidor;
- Tailscale conectado;
- convite de compartilhamento aceito.

## Windows

1. Instale o Tailscale e entre em sua conta.
2. Aceite o link enviado pelo dono.
3. Edite `Data/enUS/realmlist.wtf`, ou a pasta de idioma equivalente.
4. Use `set realmlist 100.x.y.z` com o IP informado.
5. Execute `Wow.exe`, não o Launcher oficial.

## Android/Winlator

1. Instale o Tailscale no Android, fora do Winlator.
2. Entre na conta e aceite o compartilhamento.
3. Mantenha o Tailscale conectado.
4. Dentro dos arquivos do WoW usados pelo Winlator, edite o mesmo `realmlist.wtf`.
5. Execute `Wow.exe` no container.
